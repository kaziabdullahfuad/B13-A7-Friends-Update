## Name of Project
Friend Relationship Tracker

## Description
A modern React-based web application that helps users manage and maintain their personal relationships. Users can track interactions, monitor contact frequency, and stay connected with friends through an intuitive dashboard and timeline system.

## Technologies Used
- React.js
- React Router
- Tailwind CSS
- Charts
- React Toastify
## Features
1. 🧭 Smart Navigation
Fully responsive navbar with active route highlighting
Icons for each navigation link (Home, Timeline, Stats)
2. 👫 Friend Management
Dynamic friend cards loaded from JSON data
Detailed friend profile page with stats, goals, and actions
3. ⚡ Interaction Timeline
Log interactions (Call, Text, Video) instantly
Auto-generated timeline entries with real-time toast notifications
